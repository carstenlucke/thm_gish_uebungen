# Grundlagen der Informationssicherheit — Übungsdateien

Dieses Repository gehört zu den Übungen der Veranstaltung **Grundlagen der
Informationssicherheit** (THM, Prof. Dr. Carsten Lucke). Hier liegen die
Dateien, die Sie in den Übungen herunterladen und bearbeiten. Die Anleitung
steht jeweils im Übungsblatt auf der Seite der Veranstaltung:
<https://carstenlucke.github.io/gish-next/>.

## Aufbau

Jede Übung hat ein eigenes Verzeichnis, benannt nach ihrem Thema, mit einer
eigenen `README.md`.

| Verzeichnis | Übung |
|---|---|
| [`kryptografie/`](kryptografie/) | [Kryptografie zum Ausprobieren](https://carstenlucke.github.io/gish-next/kryptografie-uebung/) |

## Dateien herunterladen

Laden Sie eine Datei am besten über ihren Link im Übungsblatt herunter. Auf
GitHub öffnen Sie die Datei und wählen „Download raw file“ (das Symbol mit
dem Pfeil nach unten). Kopieren Sie Textdateien nicht aus der Ansicht im
Browser: Schon ein anderes Zeilenende ändert den Hashwert der Datei.
